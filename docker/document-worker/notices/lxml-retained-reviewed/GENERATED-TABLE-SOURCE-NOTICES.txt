PLwC: GNU libiconv 1.18 generated alias, canonical and flag tables

The thirty supplied table headers and five gperf inputs were regenerated
byte-for-byte from the exact GNU libiconv 1.18 preferred sources. The actual
compiler dependency capture binds 244 source inputs: 237 previously reviewed
core C/header files and seven separately reviewed encoding definition files.
This supplement selects LGPL 2.1 for the original LGPL 2.1-or-later input
grants; original copyright and permissions are preserved below. The complete
LGPL 2.1 text and other original library notices remain alongside this file.

GNU gperf is a build tool. The official output-copyright policy says that its
GPL does not automatically apply to generated output; input copyright and
permissions govern output. This review binds actual input grants and executed
regeneration and does not use that policy to waive either requirement.

The release gperf 3.2 source generated five different template headers, while
all lookup/input data agreed. The unmodified historical GNU gperf C/C++ tree
at commit 09844ce4ca3d5975469640cea9c5414d5c0baa44, with five explicitly bound
auxiliary files from the official 3.2 archive, generated all thirty original
headers exactly. This demonstrates an available compatible source generator;
it does not identify the generator binary/commit used by the original author.
Generator sources and full tool licenses are retained in the source supplement.

Only this bounded source/file subset is covered. Seven original lxml native
binaries, full archive/tool/test/build-file grants and final runtime/source
collection approval remain separate G3 tasks. G3 HOLD; G4 not opened.
